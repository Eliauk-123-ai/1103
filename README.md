# 智能旅行系统

## 项目介绍
一个用 Python 编写的智能旅行规划系统。用户输入目的地和旅行天数，
程序会自动生成每日行程安排，包含景点推荐、路线顺序和当地美食建议。

## 使用的技术
Python 3

## 如何运行
1. 电脑安装 Python 3
2. 下载本仓库中的 my-project.py
3. 在命令行中进入文件所在目录，运行：

   python my-project.py

4. 按提示输入目的地（如：北京、上海）和旅行天数（1-7）

## 主要功能
- 行程规划：根据旅行天数生成每日安排
- 景点推荐：按目的地推荐热门景点并安排游览顺序
- 美食推荐：提供当地特色美食建议
- 输入校验：天数超出 1-7 或输入错误时会给出提示
